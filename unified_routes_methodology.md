# Unified marginal-oracle ablation: measurement contract

All deterministic routes use `unified_kernel.cpp` through `unified_backend.py`, compiled with `g++ -O3 -march=native -std=c++17 -fopenmp -shared -fPIC`. The SLQ kernel uses the same compiler flags, floating precision (float64), and OpenMP thread cap (8); BLAS is capped at 1. SLQ sparse products batch eight independent probe columns for CSR reuse. Deterministic initial batches use sixteen independent incidence RHS columns. Single-candidate heap refinements naturally expose less parallel work than initial full-pool evaluations.

Each repetition starts from the same immutable base matrix and candidate pool, creates a fresh greedy cache, and includes complete initialization and all k selections. Graph construction, compilation, and independent truth auditing are excluded from algorithm timings. All timed algorithms run sequentially without competing CPU experiments. Five repetitions use the same random probe seed to measure timing variance at a fixed workload; independent *random-probe quality variance* is not claimed.

`Raw-Loewner-Proj` computes the squared inverse norm from the derivative of the shifted LDL short recurrence, mathematically equivalent in exact arithmetic to the projected-tridiagonal norm. `Raw-Loewner-FullVec` carries explicit shifted solution vectors and validates their true residuals. They use precisely the same quadrature nodes and weights as IBP, with raw marginal summands `(w_j*t_j/s)*||x_j||^2/(1+r_j)` at alpha=1.

For `CRN-SLQ`, one fixed Rademacher matrix (seed 20261031+739) is reused across every set, candidate and round. p=32 is the first 32 rows of the p=128 matrix. Full greedy evaluates every unselected candidate at every round. CELF applies ordinary stamped lazy priority-queue selection to these fixed-probe point estimates, without claiming their submodularity. The matched p=128 pair isolates additional differences caused by lazy pruning from differences caused by the stochastic oracle itself. At the first divergent round, both methods have the identical prefix, so exhaustive current scores certify whether the lazy winner is strictly inferior under the same estimator.

All evaluated marginals are independently audited. For Small-BA, each visited state is diagonalized and 64-point spectral-resolvent quadrature supplies reference marginal values; final gains are differences of dense eigenvalue powers. The high-precision greedy sequence is checked against the previously saved literal Exact-Eig greedy sequence on exactly the same graph/candidates. For Medium-WS, reference marginals use independently recomputed q>=64, tol=1e-11 solves, and final gains use high-order positive path quadrature with true residual and quadrature intervals. Medium-WS reference gains are explicitly labelled high-precision numerical references, not literal full-spectrum eigendecompositions.

Incidence RHS counts and SLQ probe RHS counts are different units; the report also gives logical SpMV counts. Full-vector residual checks are recorded separately. Undercoverage of cached SLQ points relative to the *true fractional marginal* does not by itself establish that CELF pruned the wrong candidate under its own fixed-probe objective. The latter is tested by the matched exhaustive-vs-lazy pair.
